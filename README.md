

# 📊 CRM Bank Analysis Dashboard

**Power BI | Data Analytics | Business Intelligence Project**

This project focuses on analyzing **Customer Relationship Management (CRM) data from a banking environment** to uncover insights about customer behavior, product usage, and business performance.

Using **Power BI**, the raw data was transformed into an **interactive dashboard** that helps stakeholders understand key performance indicators and make data-driven decisions.

---

# 📌 1️⃣ Project Overview

The objective of this project is to analyze CRM banking data to:

- Understand customer distribution and segmentation  
- Track banking product usage and performance  
- Identify patterns in customer engagement  
- Monitor important KPIs for business decision-making  

The dashboard converts raw CRM data into **clear visual insights for management and business teams**.

---

# 📊 2️⃣ Dashboard Features

The interactive **Power BI Dashboard** includes:

- 📈 Customer growth and distribution analysis  
- 🏦 Banking product performance overview  
- 👥 Customer segmentation insights  
- 📊 Key performance indicators (KPIs)  
- 🔎 Interactive filters and slicers for dynamic analysis  

The dashboard allows users to **explore data interactively and identify trends quickly**.

---

# 💡 3️⃣ Key Insights

- Certain banking products attract **higher customer engagement** compared to others  
- Customer distribution varies across different categories and segments  
- Data visualization highlights patterns that help understand **customer behavior and product adoption**  
- Interactive dashboards make it easier to identify **high-performing areas and improvement opportunities**

---

# 📌 4️⃣ Business Recommendations

- Focus marketing efforts on **high-performing banking products**  
- Improve customer engagement strategies for underperforming segments  
- Use CRM insights to design **personalized banking services**  
- Continuously monitor KPIs through dashboards to support **data-driven decisions**

---

# 🛠️ 5️⃣ Tools & Technologies Used

- **Microsoft Power BI**
- Power Query (Data Cleaning & Transformation)
- DAX (Data Analysis Expressions)
- Data Modeling
- Interactive Dashboard Design
- KPI Tracking & Visualization
